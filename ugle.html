Den Interaktive Ugle

En kinetisk og interaktiv installation inspireret af ugglens opmærksomme væsen. Værket reagerer på bevægelse i rummet ved at dreje hovedet og ændre lysudtryk i øjnene.

Processen

Fra koncept til interaktiv ugle

FASE 1 · SKITSERING & MOP-UP

Formgivning og Proportionalitet

De første skitser og udskæringer af ugglens krop samt planlægning af mekanikken til hovedets rotation.

FASE 2 · ELEKTRONIK & LYS

Integration af Øjen-LEDs & Sensorer

Montering af LED-ringe som uglen øjne samt placering af PIR/bevægelsessensorer til registrering af besøgende.

FASE 3 · 3D-PRINTEDE MEKANISMER

Specialkonstruerede Tandhjul og Beslag

Design og 3D-print af den interne drejemekanisme, der gør det muligt for servomotoren at rotere ugglens hoved jævnt.

FASE 4 · SAMLING & SLUTJUSTERING

Færdig Installation

Kombination af fjer/overfladestruktur, mekanik og programmering for den endelige interaktive oplevelse.

Teknikken

Arduino Kildekode (Uglestyring)

ugle_styring.ino 
#include <FastLED.h>
#include <Servo.h>

#define NUM_LEDS 24
#define LED_PIN 5
#define SERVO_PIN 9
#define PIR_PIN 2

CRGB leds[NUM_LEDS];
Servo owlHead;

int headPosition = 90;
bool motionDetected = false;

void setup() {
  FastLED.addLeds<NEOPIXEL, LED_PIN>(leds, NUM_LEDS);
  FastLED.setBrightness(120);
  
  owlHead.attach(SERVO_PIN);
  owlHead.write(headPosition);
  
  pinMode(PIR_PIN, INPUT);
}

void loop() {
  motionDetected = digitalRead(PIR_PIN);

  if (motionDetected) {
    // Når bevægelse registreres: Øjnene lyser op i varm ravgul og hovedet drejer mod kilden
    fill_solid(leds, NUM_LEDS, CRGB::Amber);
    FastLED.show();
    
    // Drej hovedet søgende
    owlHead.write(45);
    delay(400);
    owlHead.write(135);
    delay(400);
    owlHead.write(90);
    delay(300);
  } else {
    // Hviletilstand: Roligt pulserende dæmpet lys i øjnene
    float breath = (exp(sin(millis()/2000.0*PI)) - 0.36787944)*108.0;
    fill_solid(leds, NUM_LEDS, CRGB::Gold);
    FastLED.setBrightness(breath);
    FastLED.show();
    
    owlHead.write(90); // Centreret position
    delay(50);
  }
}
