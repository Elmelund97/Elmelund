Interaktiv Installation · 2026

Den Interaktive Drage

En kinetisk og interaktiv installation inspireret af mysiske væsner. Værket reagerer på fysisk berøring og afstand via sensorer og skaber organiske lysmønstre og bevægelser.

Processen

Fra koncept til organisk installation

FASE 1 · SKITSERING & SKELUPBYGNING

Design og Organiske Formgivninger

De indledende skitser og opbygning af dragens bærende skelet samt test af fleksibilitet i materialerne.

FASE 2 · ELEKTRONIK & SENSORINTEGRATION

Montering af LED-effekter & Styreprint

Lodning af lyskæder og montering af sensorer, der registrerer publikums placering og interaktion.

FASE 3 · SAMLING & SLUTTEST

Det Færdige Resultat

Finalisering af den visuelle finish, finpudsning af kode og montering i udstillingsrummet.

Teknikken

Arduino Kildekode (Dragestyring)

drage_styring.ino 
 

             
        #include 

#define PIN 9


#define NUMPIXELS 270

Adafruit_NeoPixel pixels(NUMPIXELS, PIN, NEO_GRB + NEO_KHZ800);


void setup() {
  pixels.begin();

  pixels.clear();

}

void loop() {

// Changes the delay in all for loops
int del = 5;

    for (int i = 0; i < NUMPIXELS; i++)
    {
      pixels.setPixelColor(i, pixels.Color(255, 0, 0));
      pixels.show();
      delay(del);
    }
      for (int i = 0; i < NUMPIXELS; i++)
    {
      pixels.setPixelColor(i, pixels.Color(255, 255, 255));
      pixels.show();
      delay(del);
    }
}
