Roskilde Festival · 2024

Den interaktive paraply

En interaktiv kunstinstallation udviklet til Roskilde Festival. Projektet kombinerede bevægelsessensorer, programmering, servoer og interaktivt design for at skabe et fælles mødested for festivalgængerne.

Processen

Fra idé til installation

FASE 1 · IDÉ & SKITSER

Konceptudvikling & Research

De første tanker omkring hvordan en almindelig genstand som en paraply skulle forvandles til et interaktivt lysværk. Der blev lavet skitser over placering af lysdioder og sensorer.

FASE 2 · ELEKTRONIK & PROTOTYPE

Arduino & Prototype-test

Test af Arduino-mikrocontrolleren, lodning af NeoPixel LED-strips og opsætning af sensorer på breadboard for at tjekke lysmønstre og respons.

FASE 3 · FABRICATION & MONTERING

Fysisk samling

Montering af elektronikken i selve paraplystativet. Ledninger blev skjult, og strukturen blev forstærket, så den kunne modstå vind og vejr på Roskilde Festival.

FASE 4 · OPSTILLING PÅ FESTIVALEN

Det færdige resultat

Installation på festivalpladsen, hvor publikum kunne interagere med paraplyen og opleve, hvordan lyset reagerede på deres bevægelser.

Teknikken

Arduino Kildekode

paraply_styring.ino 
#include <Servo.h>

Servo servo1;
Servo servo2;
Servo servo3;
Servo servo4; 
Servo servo5; 
Servo servo6; 

bool lastState = false;
bool personNear = false;

void setup() {
  Serial.begin(9600);
  servo1.attach(8);   
  servo2.attach(9);
  servo3.attach(10);
  servo4.attach(11);
  servo5.attach(12);
  servo6.attach(13);
}

void loop() {
  Serial.println(analogRead(A0));
  Serial.println(analogRead(A1));
  Serial.println(analogRead(A2));
  Serial.println(analogRead(A3));

  if ((analogRead(A0) >= 200) || (analogRead(A1) >= 200) || 
      (analogRead(A2) >= 200) || (analogRead(A3) >= 200)) {
    personNear = true;
    Serial.println("PN t");
  } else {
    personNear = false;
  }

  if (personNear && !lastState) {
    lower();
    lastState = true;
    Serial.println("now True");
    delay(2000);
    return;
  }

  if (!personNear && lastState) {
    raise();
    lastState = false;
    Serial.println("now False");
    delay(2000);
    return;
  }

  delay(500);
}

void raise() {
  for (int i = 10; i <= 90; i++) {
    servo1.write(i);
    servo2.write(i); 
    servo3.write(i); 
    servo4.write(i);
    servo5.write(i);
    servo6.write(i);
    delay(30);
  }
}

void lower() {
  for (int i = 90; i >= 10; i--) {
    servo1.write(i);
    servo2.write(i); 
    servo3.write(i); 
    servo4.write(i);
    servo5.write(i);
    servo6.write(i);
    delay(30);
  }
}
