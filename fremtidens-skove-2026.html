Roskilde Festival · 2026

Guldsmeden · Fremtidens Skove

En mekanisk og interaktiv lys-installation formet som en gigantisk guldsmed. Værket sætter fokus på natur, biodiversitet og teknologi i samspil med festivalens område.

Processen
## Fra prototype til færdigt værk
FASE 1 · DIREKTE PROTOTYPE-ARBEJDE

Hands-on Byggefase utan skitser

Projektet sprang papirskitserne over og gik direkte til det fysiske arbejde. Der blev eksperimenteret direkte på materialerne for at teste guldsmedens vingefang, vægtfordeling og den fysiske struktur fra starten.

FASE 2 · ELEKTRONIK & MEKANIK

Motor- & Lys-test

Montering af servomotorer og LED-strips langs guldsmedens vinger og krop. Videoen herunder viser testen af vingernes mekaniske bevægelser og synkronisering.

FASE 3 · SAMLING & SAMMENSÆTNING

Færdiggørelse af skelet & vinger

Samling af alle delkomponenter, lodning af det samlede ledningsnet samt kassettering af mikrocontrolleren til udendørs brug.

FASE 4 · INSTALLATION I SKOVEN

Det færdige resultat på festivalen

Opstillingen af Guldsmeden på Roskilde Festival 2026 i området Fremtidens Skove, hvor den svævede blandt træerne med pulserende lys.

Teknikken

Arduino Kildekode

guldsmed_styring.ino 
// Indsæt din Arduino-kode til Guldsmeden herunder:

#include <Servo.h>
#include <Adafruit_NeoPixel.h>

#define LED_PIN 6
#define NUM_LEDS 90

Adafruit_NeoPixel strip(NUM_LEDS, LED_PIN, NEO_GRB + NEO_KHZ800);
Servo vingeServo;

void setup() {
  strip.begin();
  strip.show();
  vingeServo.attach(9);
}

void loop() {
  // Servo-bevægelse for vinger
  for (int pos = 0; pos <= 45; pos += 1) {
    vingeServo.write(pos);
    delay(15);
  }
  for (int pos = 45; pos >= 0; pos -= 1) {
    vingeServo.write(pos);
    delay(15);
  }
}
